Privacy Policy

Effective date: October 7, 2026

Operator: Sweet Deals PDX LLC (“we,” “our”). This policy concerns Atlas Connector, a private, locally run QuickBooks Online utility used for the operator's internal accounting administration.

What the utility accesses

After an authorized user signs in through Intuit OAuth, the current Phase 1 utility requests access to the connected QuickBooks Online company's information, account information and general-ledger transaction rows. Its current functions are read-only. The QuickBooks accounting authorization scope may technically permit read and write operations; those operations are not implemented in the current Phase 1 utility.

Where information is handled

Atlas Connector runs on the authorized user's Windows computer. The current implementation stores Intuit client credentials and OAuth tokens in the user's local Windows profile, protected using Windows per-user data protection. Retrieved accounting information is used locally for the requested verification and searches. The current utility is not designed to upload QuickBooks records to this public website or an Atlas-operated cloud database.

Sharing

The utility communicates with Intuit to authorize access and retrieve the accounting data requested by the user. We do not sell QuickBooks information. The app is for internal use by Sweet Deals PDX LLC, not offered to outside customers. Any future functionality involving remote hosting, additional data sharing, or accounting changes would require this policy and the utility's permissions and safeguards to be reviewed and updated.

Retention and control

Locally stored credentials and tokens remain on the authorized Windows profile until they are removed through the utility or the computer's storage controls. Intuit access can also be revoked through the applicable Intuit/QuickBooks app connection controls. Accounting records retained within QuickBooks remain governed by Intuit and the company's account settings.

This website

These pages are hosted through GitHub Pages. They contain no login forms, advertising pixels, or custom analytics scripts. GitHub may process requests and technical visitor information as part of hosting the site; see GitHub's privacy statement. This website itself does not request or receive QuickBooks account data.

Security

Local credential protection and OAuth reduce unnecessary exposure, but no software or storage system can guarantee absolute security. Never post OAuth tokens, client secrets, financial statements, or other confidential information in public GitHub issues.

Questions and updates

For questions about these documents, use the document repository's issue tracker, without including confidential information. This policy may be revised if the utility's behavior changes.
